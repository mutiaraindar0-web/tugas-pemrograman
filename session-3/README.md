### Tugas 2 - Kasir Sepatu (kasir.py)
Program kasir Sepatu Nike Air Jordan dengan diskon 10%

**Kode kasir.py:**
    nama_barang = "Sepatu Nike Air Jordan"
    harga = 500000
    jumlah = 2
    total = harga * jumlah
    diskon = total * 10/100
    bayar = total - diskon
    
    print("Barang:", nama_barang)
    print("Harga Satuan: Rp", harga)
    print("Jumlah Beli:", jumlah)
    print("Total: Rp", total)
    print("Diskon 10%: Rp", diskon)
    print("Total Bayar: Rp", bayar)

**Output:**
